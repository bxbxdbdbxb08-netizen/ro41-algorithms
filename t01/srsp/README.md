**Тема:** Разработка алгоритма декомпозиции общего времени в секундах на часы, минуты и секунды

---

## 1. Пошаговое описание алгоритма

1. **Инициализация и ввод:** Программа предлагает пользователю указать общее время (в секундах) в виде целого неотрицательного значения.
2. **Валидация входных данных:** 
   - Проверяется успешность приведения введенного значения к целочисленному типу.
   - Проверяется диапазон: значение не должно быть отрицательным ($S \ge 0$).
   - Если данные некорректны, выводится предупреждение об ошибке с последующим прекращением выполнения программы.
3. **Расчет временных интервалов:**
   - **Часы ($H$):** находятся с помощью операции целочисленного деления исходного времени на 3600 (количество секунд в одном часе):  
     $$H = \lfloor S / 3600 \rfloor$$
   - **Минуты ($M$):** вычисляются путем взятия остатка от деления общего числа секунд на 3600 с последующим делением этого остатка на 60:  
     $$M = \lfloor (S \pmod{3600}) / 60 \rfloor$$
   - **Секунды ($Sec$):** определяются как финальный остаток от деления исходного значения на 60:  
     $$Sec = S \pmod{60}$$
4. **Формирование вывода:** Итоговые значения компонуются в формат: `H ч. M мин. Sec сек.` и отображаются в консоли.

## 2. Псевдокод алгоритма

```text
АЛГОРИТМ КонвертерВремени
ПЕРЕМЕННЫЕ:
    строка: raw_input
    целое: total_seconds, hours, minutes, seconds

НАЧАЛО
    НАПИСАТЬ("Укажите целое число секунд: ")
    raw_input = ПРОЧИТАТЬ()

    ЕСЛИ НЕ (УспешноеЧисло(raw_input, total_seconds)) ИЛИ (total_seconds < 0) ТОГДА
        НАПИСАТЬ("Ошибка: введено некорректное или отрицательное число.")
    ИНАЧЕ
        hours = total_seconds ДЕЛИТЬ_НАЦЕЛО 3600
        minutes = (total_seconds ОСТАТОК_ОТ_ДЕЛЕНИЯ 3600) ДЕЛИТЬ_НАЦЕЛО 60
        seconds = total_seconds ОСТАТОК_ОТ_ДЕЛЕНИЯ 60

        НАПИСАТЬ(hours + " ч. " + minutes + " мин. " + seconds + " сек.")
    КОНЕЦ_ЕСЛИ
КОНЕЦ
```
