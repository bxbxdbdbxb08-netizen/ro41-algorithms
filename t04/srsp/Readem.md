## 1. Схема верхнего уровня по ГОСТ 19.701-90 (для построения в draw.io)

По ГОСТ 19.701-90 вызовы подпрограмм (методов `Grades.Read`, `Grades.IsValid`, `Grades.PrintStats`) обозначаются блоком **«Предопределённый процесс»** — это прямоугольник с двойными вертикальными линиями по бокам (в draw.io он называется *Predefined Process* или *Subroutine* в разделе Flowchart).

Расположите блоки сверху вниз:

1. **Терминатор (скругленный прямоугольник):** `Начало`
2. **Процесс (прямоугольник):**
   `count := 0`
   `sum := 0`
   `fives := 0`
3. **Предопределённый процесс (прямоугольник с двойными стенками):**
   `g := Grades.Read()`
4. **Решение (ромб) — условие цикла:** `g != Grades.Stop ?`
   * Ветка **«Да»** (вниз):
     * **Предопределённый процесс (прямоугольник с двойными стенками):**
       `valid := Grades.IsValid(g)`
     * **Решение (ромб):** `valid == true ?` (или просто `Grades.IsValid(g) ?`)
       * Ветка **«Да»** (вниз):
         * **Процесс (прямоугольник):**
           `count := count + 1`
           `sum := sum + g`
         * **Решение (ромб):** `g == Grades.Max ?`
           * Ветка **«Да»** (вниз):
             * **Процесс (прямоугольник):** `fives := fives + 1`
           * Ветка **«Нет»** (вправо в обход блока `fives := fives + 1`).
       * Ветка **«Нет»** от проверки `valid` (вправо):
         * **Данные (параллелограмм):** `Вывод "Ошибка: некорректная оценка"`
     * **Предопределённый процесс (после слияния веток внутри цикла):**
       `g := Grades.Read()`
     * Линия потока поднимается обратно на вход ромба №4 (`g != Grades.Stop ?`).
   * Ветка **«Нет»** от ромба №4 (вправо и вниз):
5. **Предопределённый процесс (прямоугольник с двойными стенками):**
   `Grades.PrintStats(count, sum, fives)`
6. **Терминатор (скругленный прямоугольник):** `Конец`
