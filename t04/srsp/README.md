## 2. Протокол выполнения контрольных тестов

### Тестовый сценарий 1. Стандартный ввод корректных данных (`5, 4, 5, 0`)
* **Входные значения:**
  ```text
  5
  4
  5
  0
  ```
* **Вывод программы:**
  ```text
  Количество оценок: 3
  Сумма оценок: 14
  Средний балл: 4.67
  Количество пятерок: 2
  ```

### Тестовый сценарий 2. Завершение работы без ввода оценок (`0`)
* **Входные значения:**
  ```text
  0
  ```
* **Вывод программы:**
  ```text
  Оценок нет
  ```

### Тестовый сценарий 3. Обработка недопустимых значений и некорректного формата (`3, 7, abc, 2, 0`)
* **Входные значения:**
  ```text
  3
  7
  abc
  2
  0
  ```
* **Вывод программы:**
  ```text
  Ошибка: некорректная оценка (ожидается число от 2 до 5, либо 0 для выхода).
  Ошибка: некорректная оценка (ожидается число от 2 до 5, либо 0 для выхода).
  Количество оценок: 2
  Сумма оценок: 5
  Средний балл: 2.50
  Количество пятерок: 0
  ```
