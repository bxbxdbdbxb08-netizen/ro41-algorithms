# СРС 4. Сортировка трех переменных с использованием передачи по ссылке (`ref`)

## 1. Принцип работы алгоритма
Задача упорядочивания значений переменных $a, b, c$ без создания массива решается с помощью трех последовательных проверок и обменов (аналог пузырьковой сортировки для трех элементов):
1. Проверка пары $a$ и $b$: если первое число больше второго ($a > b$), значения переставляются вызовом `Order.Swap(ref a, ref b)`, что обеспечивает выполнение условия $a \le b$.
2. Проверка пары $b$ и $c$: если $b > c$, вызывается `Order.Swap(ref b, ref c)`. После этого шага наибольшее из трех чисел гарантированно смещается в переменную $c$.
3. Повторная проверка пары $a$ и $b$: если после второго шага значение $a$ оказалось больше обновленного $b$, выполняется финальный обмен через `Order.Swap(ref a, ref b)`.

По завершении алгоритма числа гарантированно выстроены по неубыванию: $a \le b \le c$.
