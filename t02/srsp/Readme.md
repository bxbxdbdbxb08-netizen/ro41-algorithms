# Задание 1 (папка `t02/srsp/`)

**Ответ на вопрос «Подумайте»:** У числа `0` ровно одна цифра, а сумма цифр равна `0`. Чтобы корректно обработать случай $n = 0$ без отдельных ветвлений, используется **цикл с постусловием (`do-while`)**, так как он гарантированно выполняет хотя бы одну итерацию до проверки условия $n > 0$.

---

## 1. Псевдокод

```text
Алгоритм ПодсчетЦифрИСуммы
Ввод: n
Если n не является целым числом ИЛИ n < 0 то
    Вывод: "Ошибка: введите целое число не меньше 0."
Иначе
    сумма := 0
    количество := 0
    нц
        сумма := сумма + (n mod 10)
        количество := количество + 1
        n := n div 10
    кц при n > 0
    Вывод: количество, сумма
Все
```

## 2. Описание схемы алгоритма по ГОСТ 19.701-90 (для построения в draw.io)

Для создания файла `.png` в **draw.io** расположите блоки сверху вниз, соединяя их линиями потока:

1. **Терминатор (скругленный прямоугольник):** `Начало`
2. **Данные (параллелограмм):** `Ввод n`
3. **Решение (ромб):** `n — целое И n >= 0 ?`
   * Ветка **«Нет»** (вправо):
     * **Данные (параллелограмм):** `Вывод "Ошибка ввода"` (после него линия идет к блоку `Конец`).
   * Ветка **«Да»** (вниз):
4. **Процесс (прямоугольник):** `сумма := 0`, `количество := 0`
5. **Процесс (прямоугольник) — тело цикла:**
   `сумма := сумма + (n mod 10)`
   `количество := количество + 1`
   `n := n div 10`
6. **Решение (ромб) — проверка постусловия:** `n > 0 ?`
   * Ветка **«Да»** (влево и вверх): возврат на вход блока №5 (тело цикла).
   * Ветка **«Нет»** (вниз):
7. **Данные (параллелограмм):** `Вывод количество, сумма`
8. **Терминатор (скругленный прямоугольник):** `Конец`
