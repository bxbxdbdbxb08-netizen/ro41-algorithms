## 3. Пошаговая трассировка выполнения для значений a = 48, b = 18[cite: 1]

* Стартовые параметры: $a = 48$, $b = 18$[cite: 1].

| Шаг | Проверка условия ($b \neq 0$) | Вычисление остатка ($r := a \pmod b$) | Присваивание $a := b$ | Присваивание $b := r$ | Состояние переменных $(a, b)$ |
| :-: | :-: | :-: | :-: | :-: | :-: |
| 1 | Истина ($18 \neq 0$)[cite: 1] | $48 \pmod{18} = 12$[cite: 1] | $18$[cite: 1] | $12$[cite: 1] | $a = 18, b = 12$[cite: 1] |
| 2 | Истина ($12 \neq 0$)[cite: 1] | $18 \pmod{12} = 6$[cite: 1] | $12$[cite: 1] | $6$[cite: 1] | $a = 12, b = 6$[cite: 1] |
| 3 | Истина ($6 \neq 0$)[cite: 1] | $12 \pmod{6} = 0$[cite: 1] | $6$[cite: 1] | $0$[cite: 1] | $a = 6, b = 0$[cite: 1] |
| Конец | Ложь ($0 \neq 0$)[cite: 1] | —[cite: 1] | —[cite: 1] | —[cite: 1] | $a = 6$[cite: 1] |

**Итог работы программы:** цикл завершен, вычисленный НОД равен $a = 6$[cite: 1].
