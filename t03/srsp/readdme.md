## 1. Описание схемы алгоритма по ГОСТ 19.701-90 (для построения в draw.io)

Представленный псевдокод реализует **алгоритм Евклида** для нахождения наибольшего общего делителя (НОД) с циклом с предусловием (`пока b != 0`).

Для построения схемы в **draw.io** расположите блоки сверху вниз:

1. **Терминатор (скругленный прямоугольник):** `Начало`
2. **Данные (параллелограмм):** `Ввод a, b`
3. **Решение (ромб) — проверка корректности ввода:** `a, b — целые И a >= 0 И b >= 0 И (a != 0 ИЛИ b != 0) ?`
   * Ветка **«Нет»** (вправо):
     * **Данные (параллелограмм):** `Вывод "Ошибка ввода"` (линия от него идет к блоку `Конец`).
   * Ветка **«Да»** (вниз):
4. **Решение (ромб) — условие цикла с предусловием:** `b != 0 ?`
   * Ветка **«Да»** (вниз):
     * **Процесс (прямоугольник):**
       `r := a mod b`
       `a := b`
       `b := r`
     * Линия потока выходит снизу прямоугольника, идет влево, поднимается вверх и возвращается на вход (сверху) в ромб №4 (`b != 0 ?`).
   * Ветка **«Нет»** (вправо и вниз):
5. **Данные (параллелограмм):** `Вывод a`
6. **Терминатор (скругленный прямоугольник):** `Конец`
